Aula 09: Front-end (React/TS) e Consumo de API

Tópicos Especiais em Sistemas para Internet III | Workshop Guiado

🎯 Objetivos de Aprendizagem

  • Criar um projeto React + TypeScript com Vite.
  • Configurar o CORS no Spring Boot para permitir consumo do Front-end.
  • Consumir endpoints da API SocialConnect via Axios.
  • Renderizar dados em componentes React com tipagem forte.
  • Integrar a listagem de Beneficiários da API em uma tela real.

🏗️ Arquitetura da Integração

┌─────────────────┐         ┌─────────────────┐         ┌─────────────────┐
│   React/TS      │  HTTP   │  Spring Boot    │   SQL   │   PostgreSQL    │
│   (Front-end)   │ ◄─────► │  (API REST)     │ ◄─────► │   (Banco)       │
│   Porta 5173    │  JSON   │  Porta 8080     │         │                 │
└─────────────────┘         └─────────────────┘         └─────────────────┘

Fluxo de Dados:

  1. React faz GET /api/v1/beneficiarios
  2. Spring Boot retorna JSON com Page<BeneficiarioResponseDTO>
  3. React renderiza a lista em uma tabela

🚀 Crash Course: React + TypeScript

O que é React?

  • Biblioteca para construir interfaces de usuário com componentes reutilizáveis.
  • Usa JSX (JavaScript XML) para misturar HTML com JavaScript.
  • Gerencia estado com Hooks (useState, useEffect).

Por que TypeScript?

  • Tipagem estática: evita bugs em tempo de compilação.
  • Autocompletar inteligente na IDE.
  • Contratos claros entre Front-end e Back-end.

📦 Componentes React: O Básico

// Um componente funcional simples
function Saudacao({ nome }: { nome: string }) {
  return <h1>Olá, {nome}!</h1>;
}

// Uso:
<Saudacao nome="Maria" />

Regras:

  • Componentes começam com letra maiúscula.
  • Props são tipadas com TypeScript.
  • JSX retorna UM elemento raiz (use <></> para agrupar).

🎣 Hooks: useState e useEffect

useState: Gerenciar estado local

const [contador, setContador] = useState(0);

// Atualizar:
setContador(contador + 1);

useEffect: Efeitos colaterais (ex: buscar dados da API)

useEffect(() => {
  // Executa quando o componente monta
  fetchBeneficiarios();
}, []); // [] = executa apenas uma vez

🌐 Axios: Cliente HTTP

Por que Axios e não fetch?

  • ✅ Sintaxe mais limpa.
  • ✅ Conversão automática de JSON.
  • ✅ Interceptadores (ex: adicionar token JWT).
  • ✅ Tratamento de erros mais intuitivo.

Instalação:

npm install axios

🔧 Configuração do CORS no Backend

O Problema:

O navegador bloqueia requisições de origens diferentes (porta 5173 → 8080) por segurança.

A Solução:

Criar uma classe de configuração no Spring Boot:

package br.com.socialconnect.api.config;

import org.springframework.context.annotation.Configuration;
import org.springframework.web.servlet.config.annotation.CorsRegistry;
import org.springframework.web.servlet.config.annotation.WebMvcConfigurer;

@Configuration
public class CorsConfig implements WebMvcConfigurer {
    
    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/api/**")
            .allowedOrigins("http://localhost:5173")
            .allowedMethods("GET", "POST", "PUT", "DELETE", "PATCH")
            .allowCredentials(true);
    }
}
💡 Onde colocar: Crie este arquivo em src/main/java/br/com/socialconnect/api/config/CorsConfig.java

🎨 Componente de Listagem

Arquivo: src/components/BeneficiarioList.tsx

import { useEffect, useState } from 'react';
import api from '../services/api';
import { Beneficiario, Page } from '../types/beneficiario';

export function BeneficiarioList() {
  const [beneficiarios, setBeneficiarios] = useState<Beneficiario[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    api.get<Page<Beneficiario>>('/beneficiarios?page=0&size=10')
      .then(response => {
        setBeneficiarios(response.data.content);
        setLoading(false);
      })
      .catch(error => {
        console.error('Erro ao buscar beneficiários:', error);
        setLoading(false);
      });
  }, []);

  if (loading) return <p>Carregando...</p>;

  return (
    <table>
      <thead>
        <tr>
          <th>Nome</th>
          <th>CPF</th>
          <th>Telefone</th>
        </tr>
      </thead>
      <tbody>
        {beneficiarios.map(b => (
          <tr key={b.idBeneficiario}>
            <td>{b.nome}</td>
            <td>{b.cpf}</td>
            <td>{b.telefone}</td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}

Usando no App.tsx:

import { BeneficiarioList } from './components/BeneficiarioList';

function App() {
  return (
    <div>
      <h1>SocialConnect - Beneficiários</h1>
      <BeneficiarioList />
    </div>
  );
}

export default App;

🎯 Desafio em Duplas (45 min)

Missão:

Criar a tela de Cadastro de Beneficiário consumindo POST /api/v1/beneficiarios.

Requisitos:

  1. Formulário com campos: nome, CPF, telefone, endereço.
  2. Validação básica (campos obrigatórios).
  3. Ao submeter, fazer POST para a API.
  4. Exibir mensagem de sucesso ou erro.
  5. Redirecionar para a listagem após sucesso.

Dica:

Use useState para cada campo do formulário e api.post() para enviar.

Exemplo de estrutura:

export function BeneficiarioForm() {
  const [nome, setNome] = useState('');
  const [cpf, setCpf] = useState('');
  const [telefone, setTelefone] = useState('');
  const [endereco, setEndereco] = useState('');

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    
    try {
      await api.post('/beneficiarios', {
        nome, cpf, telefone, endereco
      });
      alert('Beneficiário criado com sucesso!');
      // Redirecionar para listagem
    } catch (error) {
      alert('Erro ao criar beneficiário');
    }
  };

  return (
    <form onSubmit={handleSubmit}>
      <input value={nome} onChange={e => setNome(e.target.value)} placeholder="Nome" />
      // ... outros campos
      <button type="submit">Cadastrar</button>
    </form>
  );
}

⚠️ Armadilhas Comuns

ProblemaCausaSolução
CORS bloqueado Backend não permite origem 5173 Verifique se o CorsConfig está no Backend
Porta errada React em 5173, API em 8080 Confira o baseURL no api.ts
useState assíncrono Estado não atualiza imediatamente Use useEffect para reagir a mudanças
Tipagem fraca Resposta da API sem tipo Sempre tipifique: api.get<Page<Beneficiario>>
Loop infinito Buscar dados fora do useEffect Use useEffect(() => {...}, [])

📝 Resumo da Aula

  • React + TS cria interfaces tipadas e reutilizáveis.
  • Axios simplifica o consumo de APIs REST.
  • CORS deve ser configurado no Backend para permitir consumo.
  • useState gerencia estado local; useEffect executa efeitos colaterais.
  • Componentes são a unidade básica do React.
